# How to use this current update

A non-custodial wallet for the Trovo Ecosystem of apps.


## How to Use 

**Step 1:**

Download or clone this branch to your system:


**Step 2:**

Install Flutter Version Manager (FVM) so that you can have different flutter versions in your machine.
You can use this video tutorial as guide to set FVM up in your machine:
```
https://www.youtube.com/watch?v=v9iRjM-K1SM&pp=ygUXZmx1dHRlciB2ZXJzaW9uIG1hbmFnZXI%3D
```

**Step 3:**

Install flutter version 3.10.5 using the fvm


**Step 4:**

After successfully setting fvm and installing flutter version 3.10.5, run:
```
flutter pub get
```
to install the various project dependecies.

**Step 5:**

Then run the project using ```flutter run``` (after configuring FVM correctly, you can refer to the video again), 
but to be on a safer side, use ```fvm flutter run```
